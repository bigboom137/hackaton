# Questline home screen art

Place your home screen images in this folder:

- Background: `home-background.jpg`
- Logo: `questline-logo.png`

The background is loaded from `css/styles.css` and uses a dark overlay so the menu stays readable. The logo is loaded from `index.html`; if it is missing, the text title appears instead. Use a wide image with a transparent background for the logo. Replace either file with your own image using the same name to update the home screen without adding player-facing upload controls.
