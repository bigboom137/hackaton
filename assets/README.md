# Questline home screen art

Place your home screen images in this folder:

- Desktop background: `home-background.jpg` (recommended 1920 x 1080 px)
- Mobile portrait background: `home-background-mobile-portrait.jpg` (recommended 1080 x 1920 px)
- Mobile landscape background: `home-background-mobile-landscape.jpg` (recommended 1920 x 1080 px)
- Logo: `questline-logo.png`

The page itself sizes to the browser window (`100vw x 100vh`), so it has no fixed webpage dimensions. The background images are cropped to fill each viewport; use the recommended sizes above for sharp results. The logo is loaded from `index.html` and is shared across all orientations; a transparent PNG around 1000 x 300 px works well. If it is missing, the text title appears instead. Replace the files here with your own images using the same names. The mobile editor has a separate full-screen Preview mode, opened from the Preview button and exited with Editor.
